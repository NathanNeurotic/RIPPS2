# Build 102 is RIPPS2 v1.0.2 beta: no more beeping on a stuck load, info pages that only go through games, a Colours page for every theme, square app cases and a tidier RIPGRID, RIPFLOW and Adapt.

## Get it
- [Download the latest RIPPS2.elf](https://github.com/akilluminati47/RIPPS2/releases/latest/download/RIPPS2.elf) (this link always gets the newest build) and [the theme pack](https://github.com/akilluminati47/RIPPS2-themes/releases/latest/download/RIPPS2-themes.zip) (edition 102: replace your Adapt folders)
- [The psx-place thread](https://www.psx-place.com/threads/ripps2-a-ps2-front-end-in-one-elf-launch-disc-storage-memory-files.51316/) and [the beta reel](https://youtu.be/LPjdK_E1jjM)

## Sound
- **No beeping while a load is stuck.** The music now fills a stalled read with silence instead of looping its last tenth of a second, and switching away no longer hangs the menu for seconds.
- The console boot sound starts with the towers. Adapt plays your ripped sounds even over an older copy.

## Every theme
- **Info pages:** Left, Right, Up and Down go through the games. No info page switches the source any more.
- **Colors and More** edits RIPGRID's and Adapt's own colours too (they were greyed out and skipped). Reset gives a theme its own back.
- **Apps** show a square PS1 case by default. Triangle on an app: **Case Shape** PS1, PS2 or Theme, kept per app.
- Reflections and cased covers fade with their page, long text slides smoothly, About and STATUS read in RIPPS2's own type, and About's credits wrap inside the panel.
- A game started from Memory Files starts its drive's games first: no more opening it in Storage before a launch.

## Themes
- **RIPGRID:** Standard glyphs (L3, R3), the grid raised to even spacing, the info page lined up, the logo just above the glass, CD player and file tree like RIPFLOW, Launch Disc and Memory Files like RIPPS2.
- **RIPFLOW:** White glyphs, hints in Sleek Case, badges and stars at their true shapes.
- **Adapt:** disc and case at real-life proportions, lined up with the list; logos just above the info glass; readable hints; the apps page fits.

## Test list
- **The beeping:** play ripped music (or the ripped menu WAV) from a slow drive or a memory card, do an in-game reset back into RIPPS2, and switch pages while it loads. Any beeping or a long freeze?
- **Boot sound:** does it start as the towers first zoom, not before the picture?
- **Info pages:** on RIPPS2, RIPGRID, RIPFLOW and Adapt, press Square, then Left and Right. Do you stay on the info page going through games?
- **File browser launch:** START DRIVES in Memory Files, open a drive you have NOT opened in Storage, start an ISO from there. Does it launch?
- **Colours:** on RIPGRID, Settings > Interface > Colors and More: can you reach and change the colour rows, and does Reset give RIPGRID's own colours back?
- **App cases:** are your apps' cases square? Set one to PS2 with Triangle > Case Shape: does it stay after a reboot?
- **Adapt:** do the disc and case line up with the list's box, top and bottom?
- **Logos:** on RIPGRID and Adapt info pages, do logos sit just above the text box for every game?
- **RIPGRID:** do the Launch Disc and Memory Files pages look like RIPPS2's, and the CD player like RIPFLOW's?
- **About:** scroll the credits on each theme. Does any line run outside the panel?
- **Fades:** open RIPPS2's info page. Does the case fade in with everything else, its reflection too?
- **Scrolling text:** a long game name in the list or a long setting value: does it slide smoothly?
- **720p and 1080i:** any of the above looking wrong in an HD mode?
