# Build 99: four builds since 95. The music gets a road of its own, Memory Files grows up, the Grid and Flow catch up, and RIPPS2 calls your drives by their real names.

## Music (98, 99)
- **Half of all music never played** (a quirk of the PS2's Vorbis library with random Ogg serial numbers): it all plays now. The music is read into memory in big pieces, so loading covers no longer starves it.

## Memory Files (98)
- Both memory cards stay after START DRIVES (MEMORY CARD 0 and 1). Paste asks YES / NO / YES TO ALL, a full card says so first, deletes are checked. Rest on a file for its details; hold to scroll.
- **Games start from here** (ISO/ZSO in CD or DVD, CUE/BIN in EMBER/games). **3D save icons** open animated, and RIP 3D ICON writes OBJ + PNG for a PC. RIPPS2's card folder has its own icon: the dead elf's hat.

## Grid and Flow (97, 98)
- RIPGRID's 720p freeze fixed; full list pages; L2/R2 turn a page; Widescreen Grid layout for 720p/1080i; Vignette Off/Weak/Full; Background blur; RIPFLOW tilts and flips. Background art fades in right behind its cover.

## Settings (96)
- Back lands on the row you came from; one plain settings face on every theme; Colors and More tooltips and Theme values; auto start can be Last Used; page buttons L1/R1 or L2/R2.

## Names and IDs (99)
- Drives are named USB, HDD, iLINK or MX4SIO by what they are, not "USB" for every `mass0:`. PS1 games flash their real disc ID for RetroGEM (RiptOPL #869). A slow iLink drive is waited for at start.

## Test list
- **Music while browsing**: scroll fast through a big list on your HDD or USB with covers loading, open info pages. Any stutter or freeze in the music? Which drive is RIPPS2 and AUDIO on?
- **STATUS > DRIVES** (FifthFox): read out what it says for every drive and for MX4SIO.
- **iLink**: does the drive show up at start now? POPSTARTER from iLink and from the APA HDD: still logo then nothing, or a crash? Neutrino on iLink?
- **MMCE beside a plain card**: Memory Files, START DRIVES: are MEMORY CARD 0 and 1 both still there?
- **RIPGRID at 720p / 1080i** with Widescreen Grid layout: does it fill the screen and stay responsive?
- **Memory Files**: start a game from DVD/ and a PS1 game from EMBER/games/; open a save's `.ico` in 3D; after any PS1 launch, look at `RIPPS2` on your memory card in the PS2 browser (the hat should ring its bell).
- **Pixel FX / RetroGEM** users: does a PS1 launch now switch to the right profile?
- **Video** (FifthFox): where was the AVI that loaded forever, a USB drive or the network?
